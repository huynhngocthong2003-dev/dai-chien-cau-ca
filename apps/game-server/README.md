# game-server (Giai đoạn 4)

Server Colyseus (Node.js + TypeScript) – **chưa triển khai**. Thư mục này giữ chỗ theo kiến trúc.
Kế hoạch: `BattleRoom` 1v1/3v3, ghép trận ELO, phòng riêng có mã, xác thực JWT Supabase, chạy lại logic `@dccc/shared` để xác minh kết quả. Xem `docs/TECHNICAL_ARCHITECTURE.md`.
